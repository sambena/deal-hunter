Query tips

Every word must be in the listing title. a|b means either one. "exact phrase" in quotes. -word excludes. Matching ignores case, dashes and spaces, so 10980xe finds "i9-10980 XE". Model numbers work better than full product names. Junk like "for parts" or "bent pins" is always filtered (edit the list in Settings).

Your watches

Everything you own: PCs and servers with their parts, plus TVs, monitors, phones, tablets, network gear, appliances and more. For PCs, Find upgrades suggests drop-in CPUs and RAM; for anything, Find upgrades with AI suggests better models and accessories, and Watch this model looks for a spare or replacement.

Checking

Local area

Local sources only show things you can pick up within this distance. eBay also uses the ZIP for shipping estimates.

eBay

Free. Covers both the nationwide search and local pickup.

How to get an eBay key (free)
  1. Go to developer.ebay.com and join the Developers Program. Your normal eBay login works.
  2. Open Application Keys and create a keyset under Production (not Sandbox). Give the app any name, e.g. "Deal Hunter".
  3. eBay asks about marketplace account deletion notifications before it switches the keyset on. Choose the exemption: you are not persisting eBay data.
  4. Copy the App ID (Client ID) and the Cert ID (Client Secret) into the boxes below, then press Save settings.

The free tier allows 5,000 searches a day, far more than Deal Hunter uses.

Reddit

No key needed. Only "selling" posts are matched: [H] item [W] PayPal/cash, or [FS]. Prices are guessed from the post text, so check the post. Nothing to set up.

Retail deals

Free, nothing to set up. Community-posted sales from Amazon, Newegg, Walmart, Best Buy, Micro Center and other stores. Prices are read from the post title, so check the post before you buy.

Best Buy open-box experimental

Free, if Best Buy approves you.

How to get a Best Buy key (free)
  1. Go to developer.bestbuy.com and choose Get API Key.
  2. Sign up and confirm your email. Best Buy sometimes asks for a business email or reviews new sign-ups by hand, so the key can take a while or be refused.
  3. Copy the key from your account page into the box below, tick Enabled, and save.

It only finds open-box items for products that match your watch, and doesn't know which store they're in.

Home Assistant

Optional. Lets My hardware import your TVs, phones, speakers, network gear and appliances. Deal Hunter only reads the device list; it never changes anything in Home Assistant.

How to get a Home Assistant token (free)
  1. In Home Assistant, click your name at the bottom left to open your Profile, then the Security tab.
  2. Under Long-lived access tokens, click Create token and name it "Deal Hunter".
  3. Copy the token (it's only shown once), paste it here with your Home Assistant address, and save.

The token can do anything your account can, so keep it private. You can delete it from the same page any time.

Discord

How to get a Discord webhook (free)
  1. In Discord, hover over the channel you want alerts in and click the gear (Edit Channel).
  2. Open Integrations → Webhooks → New Webhook. Name it "Deal Hunter" if you like.
  3. Click Copy Webhook URL, paste it below, tick Post new finds to Discord, and save.
  4. Press Send test message to check it works.

You need Manage Webhooks permission on the server. Anyone with the link can post to that channel, so keep it private.

AI

Off by default. AI only runs when you press an AI button, never in the background. Paid models show the cost and ask first, and stop working once a request could take you past your monthly limit.

How to get a Claude (Anthropic) key: pay as you go
  1. Go to console.anthropic.com and sign in. This is separate from a Claude Pro/Max subscription, which can't be used here.
  2. Open Billing and buy a few dollars of credit. $5 lasts a long time with the cheaper models.
  3. Under Settings → Limits, set a monthly spend limit. That cap is on Anthropic's side, on top of the limit above.
  4. Open API Keys → Create Key, copy it (it's only shown once), paste it below, and save.

Claude Haiku 4.5 is the cheapest. Opus 5.5 gives the best judgement on listings.

How to get an OpenAI (ChatGPT) key: pay as you go
  1. Go to platform.openai.com and sign in. A ChatGPT Plus subscription doesn't include API use.
  2. Open Settings → Billing and add a few dollars of credit.
  3. Under Settings → Limits, set a monthly budget.
  4. Open API keys → Create new secret key, copy it (it's only shown once), paste it below, and save.

When ticked, Gemini requests count as $0 and don't use up the monthly limit. Untick it if you turn on billing in Google, so real costs are tracked and capped again. Your key's tier is shown on aistudio.google.com/apikey under "Billing Tier".

How to get a Google Gemini key: free tier, then pay as you go
  1. Go to aistudio.google.com/apikey and sign in with a Google account.
  2. Click Create API key. Pick or create a Google Cloud project when asked.
  3. Copy the key, paste it below, and save.

Without billing turned on, the key uses Google's free tier: limited requests per day, and Google may use the prompts to improve its products. Turning on billing in Google Cloud lifts the limits and the cost is shown above.

How to set up Ollama (free, runs on your own computer)
  1. Install Ollama from ollama.com on a computer with a decent graphics card.
  2. In a terminal there, run ollama pull qwen3.5:4b (about 3.4 GB, fits a 6 GB graphics card).
  3. Put that computer's address in Ollama URL, e.g. http://192.168.1.50:11434. To reach it from another machine, set OLLAMA_HOST=0.0.0.0 on the Ollama computer.
  4. Type the model name (qwen3.5:4b) in Ollama model and save.

It costs nothing, but without a graphics card each answer can take a minute or more. Small local models are quick but make more mistakes about hardware than the paid models.

At home this is already set up: the URL http://192.168.86.82:11434 reaches Ollama on the Proxmox server (waking it if it's asleep) from the house network or the VPN.
